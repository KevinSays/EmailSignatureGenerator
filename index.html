Terminal signature generator

Edit the config on the left, watch it render like a fetch tool on the right. Export as HTML for your email client, or as a PNG if your client mangles CSS.

# theme — accent

zsh — ~/dotfiles/signature.conf

          

        

        

      


      

        
        
        
        
      

      

        Copy signature HTML copies the rendered block, with clickable email, phone and website links. Paste it into your email's signature settings (steps below).
        Download PNG is the safest bet if your client (Outlook desktop especially) strips fonts and colors. Embed the image instead.
        Prefer something quieter for work email? Switch background to light.
      


      

        How to add this to your email
        

          

            
            
            
            
          


          

            
    
              
  1. Click Copy signature HTML above.
    2. 
              
  2. In Gmail, click the gear icon, then See all settings.
    3. 
              
  3. On the General tab, scroll to Signature and click Create new. Give it a name.
    4. 
              
  4. Click into the signature box and paste (Ctrl+V / ⌘+V).
    5. 
              
  5. Under Signature defaults, pick it for new emails and replies.
    6. 
              
  6. Scroll to the bottom and click Save Changes.
    7. 
            

            
Gmail's mobile apps use a separate plain-text signature. Use Copy plain text for those.

          


          

            
    
              
  1. Click Copy signature HTML above.
    2. 
              
  2. In Outlook on the web (or the new Outlook app), click the gear icon, then Account → Signatures.
    3. 
              
  3. Click + New signature and give it a name.
    4. 
              
  4. Paste into the editor.
    5. 
              
  5. Choose it as the default for new messages and replies, then click Save.
    6. 
            

            
If the dark background disappears after pasting, switch to the light background, or use the PNG instead.

          


          

            
    
              
  1. Click Download PNG above. Classic Outlook often strips pasted colors and fonts, so the image is the reliable choice.
    2. 
              
  2. In Outlook, go to File → Options → Mail → Signatures…
    3. 
              
  3. Click New and name it.
    4. 
              
  4. In the editor, click the picture icon and insert the PNG. Optionally, select it and click the link icon to point it at your website.
    5. 
              
  5. Set it as the default for new messages and replies, then click OK.
    6. 
            

            
You can try pasting the HTML copy first. If it looks right, keep it, since text stays selectable and links stay clickable.

          


          

            
    
              
  1. Click Copy signature HTML (or Download PNG) above.
    2. 
              
  2. In Mail, open Mail → Settings → Signatures.
    3. 
              
  3. Select your account and click +.
    4. 
              
  4. Uncheck Always match my default message font.
    5. 
              
  5. Paste the HTML into the right-hand box, or drag the PNG in.
    6. 
            

            
Mail saves as you go. Choose the signature for each account from the dropdown under the list.

          


          
Always test it: send an email to yourself (ideally to a different provider too) and check it in both light and dark mode before you rely on it.
